# 신안 3호기 현장 3D 뷰어

`Open_Shinan3_Viewer.bat`를 실행하면 로컬 브라우저가 열립니다. Python 3과 WebGL2 지원 Edge/Chrome이 필요합니다. 이미 포함된 Three.js 및 Cannon-es를 사용하므로 인터넷이나 npm 설치가 필요하지 않습니다. 다른 프로그램이 8765 포트를 사용 중이면 `python serve.py --port 8766`으로 실행하세요.

## 확인 방법

- 전체 조감도, 모듈 디테일, 전기실 외관, 수직 배치도, 현장 보행을 선택합니다.
- 드래그 회전, 휠 확대, 오른쪽 드래그 이동. 패널 클릭 또는 `S3-G0600-R1-M01` 형태의 ID 검색으로 모듈을 선택합니다.
- 보행에서는 WASD 이동, 드래그 시선 변경, Shift 빠르게 이동합니다. 지면과 어레이·건물 충돌을 적용했습니다.
- 햇빛 슬라이더와 렌더 품질을 조절합니다. 최고 품질은 고성능 GPU용입니다. 느리면 표준 품질을 선택하세요.
- 화면 저장은 UI를 제외한 현재 3D 화면을 PNG로 저장합니다.

## 원자료와 정확도

전기 CAD `3SA-E-11210_C.dwg`에서 추출한 1,500개 어레이 그룹, 30,000개 모듈 배치를 사용합니다. 모듈 정격 합계는 7.5 MWp입니다. 로컬 좌표는 동쪽 X, 북쪽 N이며 뷰어는 Three.js Y-up으로 변환합니다. 실측 지형·지리좌표계가 없으므로 지면은 평탄하게 표시합니다.

패널 셀 표면, 지표, 콘크리트 등의 텍스처는 시각화용 합성 재질입니다. 제공된 지표 사진은 공사 전 자료이며, 완공된 설비의 사진과 동일한 외관을 보장하지 않습니다. 창호·배관·지지대 상세에는 일반화와 추정이 포함됩니다. 제3전기실 입면 요소를 제1·2전기실에도 일반화했습니다. 앱의 '자료와 재현 범위'에서 상세 설명과 원자료 비교를 확인할 수 있습니다.

모듈 ID는 도면의 식별자이며, 현장 시리얼이나 열화상 분석 결과와 연결되지 않았습니다. 선택 강조색은 결함을 뜻하지 않습니다.

Cannon-es 중력과 충돌은 보행 체험용입니다. 어레이 전체를 단순 박스 충돌체로 처리하므로 패널 아래로 들어갈 수 없습니다. 구조·풍하중·발전량을 계산하는 공학 시뮬레이션이 아닙니다.

보행자는 입력 속도로 움직이는 탐색용 컨트롤러이며, 지면 마찰이 조작을 상쇄하지 않도록 마찰을 0으로 설정했습니다. 중력과 지면·벽면의 충돌 응답은 유지합니다. 이 설정은 실제 사람이 걷는 생체역학이나 지표 마찰계수를 재현하지 않습니다.

## 재현 가능한 검토

`?view=overview`, `?view=detail`, `?view=building`, `?view=top`으로 동일 시점을 엽니다. `&clean=1`은 UI를 숨깁니다. `window.__SHINAN_QA__`에는 개수, 선택 ID, FPS, draw calls, 보행 상태 및 충돌 검증 함수가 있습니다.

## 라이선스

Three.js 0.180.0과 Cannon-es 0.20.0은 MIT 라이선스이며 각 패키지의 LICENSE 파일을 포함합니다. 원본 CAD와 사진의 권리는 해당 자료 소유자에게 있습니다.

## 전기실 내부 탐색 업데이트

1. 왼쪽 **전기실 내부 탐색**에서 1·2·3호 전기실을 선택합니다.
2. **출입구에서 보행 시작**을 누르면 건물 바깥 출입구 앞에 섭니다.
3. W로 문 앞까지 이동하고 **E 또는 문 클릭**으로 문을 엽니다.
4. WASD로 실내에 들어가고 마우스를 드래그해 둘러봅니다. 밖으로 나올 때도 같은 방식입니다.
5. 문을 닫으려면 문짝에서 한 걸음 떨어진 뒤 E를 누릅니다. 문 가까이에 사람이 있으면 닫힘을 중단합니다.

3개 전기실의 내부 설비 62개와 식별표, 벽·바닥·천장·조명, 출입문 6개를 추가했습니다. 1호 전기실에는 3SA-E-10110에 표시된 감시실 구획, 실내 출입문, 책상 2개, 통신 랙과 모니터도 표현했습니다. 내부는 케이블 보기를 켜지 않아도 보입니다. 중앙 대형 장비 반입문은 닫힌 고정 형상이며 개폐 조작은 인원 출입문에 적용됩니다.

기존 건물 전체 박스 충돌을 벽·문·설비별 충돌로 바꿨습니다. 진입 경사로, 문 폭·경첩 방향, 표면 마감, 조명과 트렌치 표현, 가구 상세·일부 설비 높이는 시각화용 추정입니다. 창은 유리 면 표현이며 실제 개구부·투명 창문은 아닙니다. 완공 실내 사진이 없어 AAA급 실사 또는 현장과 동일한 외관으로 승인하지 않았습니다.

`Blender/Shinan3_Interiors.glb`는 같은 전기실 형상을 Blender 등에서 불러올 수 있는 교환 파일입니다. `Shinan3_Refined.blend`의 `14_Walkable_Electrical_Rooms`에도 통합했습니다. 이전 외관 컬렉션은 비교용으로 숨겨 보존했습니다. 정적 표면은 재질별로 병합되어 있고 문 경첩은 별도 오브젝트입니다. E 키 개폐와 보행 충돌은 ThreeJS 뷰어 기능이며 Blender에는 정적 편집 모델로 제공됩니다.

검토 기록: `Review/interior_browser_validation.json`, `Review/interior_review.md`.

## 날짜·위치에 따른 하루 그림자

ThreeJS 뷰어 하단의 **날짜·일조 설정**을 엽니다. 날짜를 선택하고 **날짜·위치 적용**을 누른 뒤, 시간 슬라이더를 움직이거나 **일출 / 남중 / 일몰**을 누르세요. **하루 재생**은 일출부터 일몰까지 시간을 진행하며, 다시 누르면 일시 정지합니다. 조감도와 모듈 디테일 모두에서 사용할 수 있습니다. 모듈 근처의 그림자는 디테일 시점에서 더 선명하게 보입니다.

- 시각은 PC의 시간대와 무관하게 한국시간(KST, UTC+9)입니다. 남중은 태양이 가장 높이 지나가는 시각이며 시계의 12:00과 다릅니다.
- **현장 위치·진북 보정**을 펼치면 위도, 경도, 도면 북쪽 방위각을 수정할 수 있습니다. 방위각은 진북에서 시계방향이며 0°는 도면 북쪽과 진북이 같은 경우입니다. 적용한 설정은 해당 브라우저에 저장됩니다.
- 기본값은 기존 VWorld 주소 검색 좌표(북위 약 34.774479°, 동경 약 126.158652°)입니다. 3호기 측량 기준점 또는 도면 진북 정합이 검증된 값은 아닙니다.
- NOAA fractional-year 태양 위치 근사식을 사용합니다. 인터넷이나 지도 키 없이 계산하며, 평탄한 지평선 기준 일출·일몰(-0.833°)과 태양 중심의 기하학적 고도를 구분합니다. 태양 중심이 지평선 아래이면 직사 그림자를 끕니다.
- 맑은 날의 모델 그림자 미리보기입니다. 주변 지형·수목 높이, 건축 상세가 추정이므로 실제 일조 시간·발전량·음영 손실 분석 결과가 아닙니다. 낮은 태양의 긴 그림자는 그림자 맵의 범위·해상도 제한을 받습니다.
- 이번 날짜·시간 조작은 ThreeJS 뷰어에 적용됐습니다. Blender 파일은 별도의 정적 조명 장면입니다.
